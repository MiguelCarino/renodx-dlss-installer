DLSS 5 for Linux

Neural rendering in your Proton games.
Checked first, then installed.

DLSS 5 for Linux finds your Steam games, says which ones the DLSS 5 neural pass can work in, and installs it with the Proton settings it needs.

  • Will this game work? A probe reads its folder and rates it supported, partial, unsupported or blocked before anything is copied.
  • Online game with anti-cheat? It refuses to install there. This is for single-player games.
  • No game handy? Run the same model over a picture or a video, sound kept. It also tells you when footage is 2D animation, where the model changes little.
  • Made for NVIDIA RTX 40 cards. AMD RX 6000/7000/9000 is experimental; RTX 20, 30 and 50 are not supported yet.

DLSS 5 for Linux on Fedora

One command; dnf downloads the package from the release and what it needs from Fedora:

sudo dnf install https://github.com/MiguelCarino/renodx-dlss-installer/releases/download/v0.0.6/dlss5-linux-0.0.6-1.fc44.noarch.rpm

Then open DLSS 5 for Linux from your application menu, or run dlss5-linux-gui. The command line is dlss5-linux --help.

The package has no architecture of its own and installs on current Fedora releases. It also recommends GTK 4, libadwaita and WebKitGTK for the app's own window; without them it opens in your browser. Check the download against SHA256SUMS.

DLSS 5 for Linux AppImage

1. Make it runnable and start it, from the folder you downloaded it to:

chmod +x DLSS5_for_Linux-0.0.6-x86_64.AppImage
./DLSS5_for_Linux-0.0.6-x86_64.AppImage

2. Have the usual tools installed. FFmpeg is inside; the rest comes from your system: python3, curl, unzip, binutils, 7-Zip and xdg-utils. On Debian or Ubuntu:

sudo apt install python3 curl unzip binutils p7zip-full xdg-utils

3. Pick a game in the app, press Install, and set the launch options it shows in Steam. It opens in its own window when PyGObject with GTK 4, libadwaita and WebKitGTK 6 is installed, and in your browser otherwise.

No FUSE on your system? Add --appimage-extract-and-run after the file name. The command line is the same file followed by cli --help. SHA256SUMS
